# VeneraNext JS 漫画源搭建原理与接口文档

## 一、架构概述

VeneraNext 采用 **JS 源插件系统** 作为漫画数据来源的核心架构。源以独立 `.js` 文件形式存在，通过继承 `ComicSource` 基类声明能力，由 ArkTS 侧的 `JsRuntime` 加载到 C++ JSVM 中执行，实现与宿主 App 的双向通信。

### 1.1 两阶段解析

| 阶段 | 名称 | 实现 | 产出 |
|------|------|------|------|
| A 阶段 | 静态正则解析 | `ComicSourceParser.ets` | 从源文件文本中提取 key/name/version/能力掩码/settings/account 等元信息，**无需执行 JS** |
| B 阶段 | JSVM 真引擎解析 | `JsRuntime.ets` 的 `enrich*()` 方法 | 将源加载到 JSVM 中执行，获取 explore/category/searchOptions/favorites 等运行时才能确定的精确信息 |

两阶段产出同构的 `ComicSourceMeta`，A 阶段用于 UI 快速展示（源列表、能力标签），B 阶段用于实际调用时补全精确信息。

### 1.2 源生命周期

```
扫描磁盘 .js 文件
    ↓
ComicSourceParser.parse() — A 阶段正则解析
    ↓
ComicSourceManager.addJsSource(meta) — 注册到源池
    ↓
用户点击源 / 首次调用
    ↓
JsRuntime.ensureLoaded(key) — 加载 init.js + 源脚本到 JSVM
    ↓
源实例 init() — 源初始化（如恢复登录态）
    ↓
enrichSettings / enrichExplore / enrichCategory / enrichSearchOptions / enrichFavorites — B 阶段补全
    ↓
call* 方法按需调用 — 搜索/详情/章节/收藏/评论等
```

### 1.3 通信机制

源脚本通过全局 `sendMessage(message)` 函数与宿主通信，宿主侧 `JsRuntime.handleMessage()` 分发到各处理器：

- **同步方法**：`load_data`/`save_data`/`load_setting`/`convert`/`cookie`/`html`/`image`/`random`/`uuid`/`isLogged`/`getLocale`/`getPlatform` — 直接返回值
- **异步方法**：`http`/`delay`/`compute`/`UI` — 返回 Promise

### 2.1 基本模板

```javascript
class MySource extends ComicSource {
    // ===== 元信息（必需） =====
    key = "mysource"              // 源唯一标识，仅 [a-zA-Z0-9_]

    minAppVersion = "1.0.0"       // 最低 App 版本要求
    url = "https://example.com"   // 源网站地址

    // ===== 漫画 ID 规则（可选） =====
    // 搜索框输入命中此正则时，可直接按 ID 打开详情
    // idMatch: "^(\\d+|jm\\d+)$"

    // ===== 发现页（可选） =====
    explore = [
        {
            title: "热门",
            type: "multiPageComicList",  // singlePageWithMultiPart | multiPartPage | multiPageComicList | mixed

            // loadNext: async (next) => { /* 游标式分页，返回 {comics: Comic[], next: string} */ }
        }
    ]

    // ===== 搜索（可选） =====
    search = {
        // load: async (keyword, options, page) => { /* 分页式 */ }
        // loadNext: async (keyword, options, next) => { /* 游标式 */ }
        optionList: [
            {
                label: "排序",
                type: "select",  // select | multi-select | dropdown
                options: { "popular": "热门", "latest": "最新" },
                defaultValue: "popular"
            }
        ]
    }

    // ===== 漫画详情与章节（可选） =====
    comic = {
        loadInfo: async (id) => { /* 返回 ComicDetails */ },
        loadEp: async (comicId, epId) => { /* 返回 {images: string[]} */ },
        // onImageLoad: async (url, comicId, epId) => { /* 返回 ImageLoadingConfig */ },
        // loadComments: async (comicId, subId, page, replyTo) => { /* 返回 {comments, maxPage} */ },
        // sendComment: async (comicId, subId, content, replyTo) => { /* 返回任意值 */ },
        // likeComment: async (comicId, subId, commentId, isLike) => { /* 返回任意值 */ }
    }

    // ===== 分类（可选） =====
    category = {
        title: "分类",
        enableRankingPage: true,
        parts: [
            {
                name: "标签",
                type: "fixed",  // fixed | random | dynamic

                    { label: "动作", target: { page: "category", attributes: { category: "action" } } },
                    { label: "搜索", target: { page: "search", attributes: { text: "keyword" } } }
                ]
            }
        ]
    }

    // ===== 分类结果加载（可选） =====
    categoryComics = {
        load: async (category, param, options, page) => { /* 返回 {comics, maxPage} */ },
        optionList: [ /* 同 search.optionList */ ]
    }

    // ===== 设置（可选） =====
    settings = {
        imageQuality: {
            title: "图片质量",
            type: "select",  // select | switch | input | callback
            default: "high",
            options: ["low", "medium", "high"]
        },
        enableCache: {
            title: "启用缓存",
            type: "switch",
            default: true
        },
        clearCache: {
            title: "清除缓存",
            type: "callback"
            // callback: () => { /* 点击时执行 */ }
        }
    }

    // ===== 账号（可选） =====
    account = {
        // login: async (account, password) => { /* 账密登录 */ },
        // loginWithWebview: { url: "https://example.com/login" },
        // loginWithCookies: {
        //     validate: async (cookies) => { /* 校验 cookies */ },
        //     fields: ["session", "token"]
        // },
        // logout: () => { /* 登出 */ }
    }

    // ===== 网络收藏（可选） =====
    favorites = {
        title: "我的收藏",
        multiFolder: true,
        loadComics: async (page, folderId) => { /* 返回 {comics, maxPage} */ },
        // loadNext: async (next, folderId) => { /* 游标式 */ },
        loadFolders: async (comicId) => { /* 返回 {folders, favorited} */ },
        addOrDelFavorite: async (comicId, folderId, isAdding, favId) => { /* 返回任意值 */ },
        // addFolder: async (name) => { /* 新建收藏夹 */ },
        // deleteFolder: async (folderId) => { /* 删除收藏夹 */ },
```

| 字段 | 检测关键词 | 说明 |
|------|-----------|------|
| `hasExplore` | `explore` | 发现页 |
| `hasSearch` | `search` | 搜索 |
| `hasLoadInfo` | `loadComicInfo` 或 `loadInfo` | 漫画详情 |
| `hasLoadEp` | `loadComicPages` 或 `loadEp` | 章节图片 |
| `hasSettings` | `settings` | 设置项 |

## 五、宿主侧调用接口（JsRuntime call* 方法）

以下为 ArkTS 侧 `JsRuntime` 暴露的调用接口，供 App 内部调用源能力：

### 5.1 核心调用

| 方法 | JS 表达式 | 返回值 JSON |
|------|----------|-------------|
| `callSource(key, expr)` | 任意表达式 | 任意 JSON |
| `callLoadInfo(sourceKey, id)` | `__m.comic.loadInfo(id)` | ComicDetails（Map 已归一化为普通对象） |
| `callLoadEp(sourceKey, comicId, epId)` | `__m.comic.loadEp(comicId, epId)` | `{images: string[]}` |
| `callOnImageLoad(sourceKey, url, comicId, epId)` | `__m.comic.onImageLoad(url, comicId, epId)` | ImageLoadingConfig 或 null |
| `callModifyImage(sourceKey, key, code)` | 执行 modifyImage 源码 | 还原后位图 key（number） |

### 5.2 搜索与分类

| 方法 | JS 表达式 | 返回值 JSON |
|------|----------|-------------|
| `callSearchLoad(sourceKey, keyword, options, page)` | `__m.search.load(keyword, options, page)` 或 `__m.search.loadNext(keyword, options, null)` | `{comics: Comic[], maxPage: number}` |
| `callSearchLoadNext(sourceKey, keyword, options, next)` | `__m.search.loadNext(keyword, options, next)` | `{comics: Comic[], next: string}` |
| `callCategoryComicsLoad(sourceKey, category, param, options, page)` | `__m.categoryComics.load(category, param, options, page)` | `{comics: Comic[], maxPage: number}` |

### 5.3 发现页

| 方法 | JS 表达式 | 返回值 JSON |
|------|----------|-------------|
| `callExploreLoad(page, pageNo)` | 按 type 分派：`__m.explore[i].load()` / `.load(pageNo)` / `.loadNext(null)` | 按 type 不同 |
| `callExploreLoadNext(page, next)` | `__m.explore[i].loadNext(next)` | `{comics: Comic[], next: string}` |

### 5.4 网络收藏

| 方法 | JS 表达式 | 返回值 JSON |
|------|----------|-------------|
| `callFavoriteLoadComics(key, page, folderId)` | `__m.favorites.loadComics(page, folder)` | `{comics, maxPage}` |
| `callFavoriteLoadNext(key, next, folderId)` | `__m.favorites.loadNext(next, folder)` | `{comics, next}` |
| `callFavoriteLoadFolders(key, comicId)` | `__m.favorites.loadFolders(comicId)` | `{folders, favorited}` |

| `callFavoriteDeleteFolder(key, folderId)` | `__m.favorites.deleteFolder(folderId)` | 任意值 |

### 5.5 评论

| 方法 | JS 表达式 | 返回值 JSON |
|------|----------|-------------|

### 5.6 设置与账号

| 方法 | JS 表达式 | 说明 |
|------|----------|------|
| `callSettingCallback(key, settingKey)` | `__m.settings[settingKey].callback()` | 触发 callback 类型设置 |

## 六、设置类型详解

| 类型 | UI 呈现 | JS 声明 | 说明 |
|------|---------|---------|------|
| `input` | 文本输入框 | `{ title, type: "input", default: "值" }` | 自由文本输入 |
| `select` | 下拉选择 | `{ title, type: "select", default: "值", options: ["a","b"] }` | 单选下拉 |
| `switch` | 开关 | `{ title, type: "switch", default: true }` | 布尔开关 |
| `callback` | 按钮 | `{ title, type: "callback", callback: () => {} }` | 点击触发回调 |

select 的 options 支持两种写法：
- 简单数组：`options: ["a", "b"]`
- 带标签数组：`options: [{value: "a", label: "选项A"}, {value: "b", label: "选项B"}]`

## 七、账号登录方式

| 方式 | JS 声明 | 说明 |
|------|---------|------|
| 账密登录 | `account.login = async (account, password) => {}` | 登录成功后 App 自动存储 [账号, 密码] |
| Cookies 登录 | `account.loginWithCookies = { validate: async (cookies) => {}, fields: ["session"] }` | 用户填入 cookie 值，validate 校验通过后存储 |
| WebView 登录 | `account.loginWithWebview = { url: "https://..." }` | 弹出 WebView 页面，用户手动登录后提取 cookies |

登录过期自动重登：`retryZone` 机制在调用失败时自动用存储的账号密码执行 `reLogin`，然后重试一次。

| `singlePageWithMultiPart` | 单页多分区 | `load()` 无参数 | 无分页 |
| `multiPartPage` | 多分区页 | `load()` 无参数 | 无分页 |
| `multiPageComicList` | 多页漫画列表 | `load(page)` 或 `loadNext(next)` | 页码或游标 |
| `mixed` | 混合页 | `load(page)` | 页码 |

## 九、源文件存放与命名

- **存放路径**：App 沙箱 `filesDir/sources/` 目录
- **文件命名**：`<key>.js`（key 即源声明的 `key` 字段）
- **文件要求**：必须包含 `class XXX extends ComicSource`，且 `key` 字段非空、仅含 `[a-zA-Z0-9_]`

## 十、版本兼容

- `minAppVersion`：源声明的最低 App 版本，低于此版本时 App 会提示不兼容
- `compareSemVer(v1, v2)`：语义化版本比较，格式 `major.minor.patch`
- `APP.version`：源脚本内可读取当前 App 版本做条件分支
